# Daisy 1.0.7.38 — dependable dictation, steadier connections

## Fixed

- **Dictation now gets a second chance when the first decode comes back empty.** If the biased transcription pass produced no text, Daisy used to paste nothing even though it heard you. It now retries with an unbiased pass before giving up, so short phrases and custom-vocabulary dictation are much less likely to disappear.
- **MCP clients stay connected together.** Several SSE clients can now use Daisy's local MCP server at the same time without falling into a 15-second reconnect loop. If the server port is temporarily busy, Daisy also retries the bind instead of silently giving up.

## Changed

- **Clearer dictation diagnostics.** When the fast dictation engine misses, the log now records the reason, making support and troubleshooting more useful.
