# Daisy 1.0.7.40 — dependable update checks

## Fixed

- **Updates are checked in the background immediately after Daisy launches.** With Automatic update enabled, Daisy no longer waits for the hourly schedule or a manual button press before discovering a new release.
- **The update cycle now uses Sparkle's normal background flow.** This preserves Sparkle's own scheduling and install behaviour while keeping the launch experience non-modal.
