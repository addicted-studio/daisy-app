# Daisy 1.0.7.41 — product names in dictation

## New

- **Product names stay in their canonical Latin spelling.** Russian and other non-Latin dictation now restores names such as Figma, GitHub, Zoom, Notion, Claude, and many more across every transcription engine.
- **Your vocabulary still wins.** Built-in corrections are deliberately conservative and never override a custom Dictation Vocabulary rule.
- **Optional one-tap learning from voice polish.** If Daisy notices a product name restored by polish that it does not already know, it can offer to save that correction for future dictation.

## Settings

- **New “Fix product names” switch** in Transcription, enabled by default. Turn it off if you prefer the literal spelling from the speech engine.
