# Daisy 1.0.7.43 — MCP connections

- **Connect Daisy to Codex and Cursor in one click.** Daisy adds and maintains the local MCP connection without exposing recordings to the internet.
- **A clearer MCP connections screen.** Connected apps are now compact rows with their status and actions together; server status is shown once, without technical error text.
- **Better help when the MCP port is busy.** Daisy explains how to resolve a port conflict instead of showing a raw network error.
- **More deliberate privacy controls.** Access tokens and permissions remain available under Privacy, with shorter explanations.
