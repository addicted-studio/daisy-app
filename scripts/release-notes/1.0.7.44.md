# Daisy 1.0.7.44 — token usage and cost estimate

## Added

- Home now shows tokens used by Daisy during the current month for every connected AI provider.
- For supported Claude and OpenAI models, Daisy also shows an approximate USD cost for its own paid API calls. Cache reads, cache writes, and Claude web searches are included.

## Improved

- Token usage is now recorded even when a provider returns a successful response that Daisy cannot turn into a summary.
- A Claude web search is visible in the usage card even when it reports no model tokens.
- Local models stay clearly marked as free; an unknown cloud model shows that its price is unavailable instead of incorrectly showing $0.
