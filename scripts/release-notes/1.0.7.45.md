# Daisy 1.0.7.45 — tokens by model

## Improved

- The Home token card now names the exact model whose usage it shows, instead of grouping different models under one provider.
- Token totals and estimated USD cost now have the same model-level scope.
- Added a compact 14-day usage graph so it is easy to see whether token use was steady or happened in a burst.
- Simplified the card: the month and the “Spent by Daisy” provider line are gone; the total is labelled directly as tokens.
