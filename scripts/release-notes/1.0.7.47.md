# Daisy 1.0.7.47 — calmer summaries, richer meeting context

## Added

- Choose when Daisy writes meeting summaries: after each meeting, at the end of the day, or only when you ask. The end-of-day pass waits until the Mac is idle, never competes with recording, and resumes unfinished recent meetings safely.
- Add any app from Applications to Daisy’s auto-recording list. This is useful for less common meeting tools without waiting for an app update.
- Screenshots now have a timeline. Browse distinct screens in a meeting, click a transcript timestamp to open what was on screen then, and move in either direction between the transcript and frames.
- A new option keeps recognized screen text in the transcript and search but excludes it from summary prompts when a screen share is not relevant.

## Improved

- Updated cloud and local model choices, including current Anthropic and OpenAI models; local model servers now report their installed models instead of relying only on a stale list.
- The token card now reports a month-wide total across models, a stacked daily graph, a per-model legend, and each model’s own estimated cost.
- Daisy explains likely context-window overflow from local models instead of presenting it only as an invalid summary response.
- Launch is quicker: Daisy no longer asks the network about a transcription model already stored on your Mac.

## Fixed

- Fixed a pre-meeting brief that could keep spinning, and made “Save Log Report…” save logs without trying to open a mail client.
- Fixed summary timing initialization and token-chart layout issues.
