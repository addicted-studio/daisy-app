# Daisy 1.0.7.49 — smoother voice profiles and screen summaries

## Improved

- Voice Profile is easier to read and configure: the meetings option is now a compact Settings row, and long profiles size correctly instead of squeezing into a narrow column.
- Screen-capture frames are stored as high-quality JPEGs, substantially reducing disk use while preserving OCR readability.

## Fixed

- Screen OCR now releases image memory after each frame, preventing it from shrinking the available context for summaries after longer meetings.
- Screenshot timelines stay in chronological order even in recordings longer than four hours.
