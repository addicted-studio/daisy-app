# Daisy 1.0.7.50 — keyboard layout fixes

## New

- Fix text typed in the wrong keyboard layout: use the new shortcut for selected text, or let Daisy correct confirmed gibberish as you finish a word.
- Automatic correction can safely handle Return: the corrected word is inserted before the message is sent.
- Optionally switch to the intended input source after a correction.

## Improved

- Russian localization now covers the keyboard-layout settings and shortcut controls.

## Fixed

- Layout fixing preserves selected spaces and line breaks.
