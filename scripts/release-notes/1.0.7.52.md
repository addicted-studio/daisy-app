# Daisy 1.0.7.52 — more complete follow-ups

## New

- Ask Daisy to draft a follow-up in your own voice when your Voice Profile is available.
- Kimi (Moonshot) is available as a summary provider: a 256K-token context at a fraction of the price of the other cloud options, which suits long meetings. Moonshot states that requests to its API are processed in China — if that matters for your meetings, stay with another provider.
- Daisy remembers the application builds that have run on this Mac for clearer diagnostics.

## Fixed

- Anthropic summaries now include every text block in a response, rather than only the first one.
