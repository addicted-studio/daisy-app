# Daisy 1.0.7.53 — undo a layout fix with one keypress

## New

- Press the fix shortcut right after an automatic layout correction to undo it — now works in every app, including Telegram, Slack, and web-based editors where Daisy couldn't previously confirm the undo. Undoing a word also teaches Daisy to leave it alone next time.
- Token usage on Home now shows the last 28 days, not the current calendar month, so the card isn't near-empty on the 1st.

## Fixed

- The keyboard-shortcut recorder no longer lets you bind a bare ⌘-letter combo (⌘C, ⌘V, ⌘Z, …) as a global shortcut — that used to silently shadow the system shortcut everywhere on the Mac.
