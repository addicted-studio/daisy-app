# Daisy 1.0.7.54 — a simpler start

## New

- The first-run experience is now shorter and clearer: one permissions screen, a simpler setup flow, and an optional Google Calendar connection.
- Choose automatic keyboard-layout fixing while setting up Daisy.
- Daisy follows the macOS interface language by default; you can still choose a language in Settings.
- Kimi (Moonshot) is available as a summary provider.

## Improved

- The home screen carries the useful setup guidance instead of adding another onboarding step.
- Daisy can explain why a keyboard-layout fix did not run and undo a recent layout correction with one shortcut.
- Token spending is shown for the latest 28 days.

## Fixed

- Cancelling Google sign-in no longer surfaces an unnecessary error.
- Daisy no longer snaps the window while finishing onboarding.
