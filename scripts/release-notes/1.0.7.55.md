# Daisy 1.0.7.55 — a smoother setup

## Fixed

- Automatic keyboard-layout fixing can now wake the accessibility tree in Chromium and Electron editors, so it works in more chats and browser-based apps.
- If macOS asks to quit and reopen Daisy while you grant Screen Recording, setup resumes where you left off instead of starting over.

## Improved

- Screen Recording appears last in the setup permissions flow, so a required restart is less disruptive.
