# Daisy 1.0.7.57 — summaries through your accounts

## New

- OpenAI summaries can now use the ChatGPT account already signed in through ChatGPT/Codex, without adding an OpenAI API key. API-key mode stays available and keeps its own model and credentials.
- Cursor joins the summary providers with API-key support and an experimental Cursor-account mode through Cursor Agent CLI.
- Account connections now share clear installed, signed-out, connecting, connected, expired-session, plan-limit and error states, with model selection and disconnect controls.
- Daisy shows a one-time privacy disclosure before sending a full transcript through an account-backed cloud provider.
- Account-backed requests now show local 28-day usage facts — provider, model, request count, result and duration — without inventing token counts or per-request prices.

## Safety

- Local agent clients run without a shell, in a fresh private temporary folder, with bounded output, timeout and cancellation. Transcript text travels through stdin and raw agent diagnostics are never shown or logged.
- Codex summaries disallow approvals, tools and file changes. Cursor never runs with `--force`, installs project-level deny rules for shell, file access and MCP, and remains explicitly marked Experimental because Cursor cannot documentably disable every agent tool.

## Improved

- New account connection controls, privacy messages and recovery states are available in English and Russian.
- Summary providers now share one canonical structured JSON schema, with stronger handling for malformed replies, long transcripts, prompt injection and concurrent requests.
